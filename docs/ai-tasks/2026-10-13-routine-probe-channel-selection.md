## 行为

入口为调权中心 → 规则设置 → 运行规则 → 探针与恢复 → 常态探针渠道范围。保留启用常态探针总开关，新增全部符合条件的渠道/仅指定渠道，支持按名称、ID、模型搜索多选，保存后生效。

- 策略 JSON 新增 `routine_probe_selected_only`（默认 false）和 `routine_probe_channel_ids`（默认 []）。旧配置保持全选语义，指定且空列表明确表示没有渠道运行常态探针；新增渠道不会自动加入指定范围。ID 限制为唯一正安全整数，列表最多 10000 项。
- 选中渠道仍须满足自动模式、单模型、正基础权重等原条件。总开关关闭时不运行任何常态探针；再次开启保留渠道选择。
- 未选渠道退出定时和错误加速探针。调度配置核对周期 5 秒，数据库耗时另计；在途取消沿用 canceled，不累计故障。迟到故障触发前再次读取最新策略，未选则拒绝。
- 普通评估过滤未选渠道的旧探针样本，不进入自身系数、最低样本资格或同模型基线；综合倍率独立排除旧探针系数。真实流量仍可正常调权，熔断恢复探测继续运行。
- 不直接清零或重置线上权重，不撤销已经确认的熔断，不删除历史探针。历史评估按其参数快照解释；覆盖提示按已保存范围显示，草稿不改变运行提示。
- 页面保留已选但目录暂缺的 ID；切站重新读取配置。旧 Server 未返回选择能力字段时禁用范围控件并拦截指定范围保存，避免后端忽略字段后继续全部探测。
- 无数据库迁移或 Agent 改动，需配套更新 Server/Web。执行前容量/策略复核由结构体直接比较改为深度比较，包含新增列表。
