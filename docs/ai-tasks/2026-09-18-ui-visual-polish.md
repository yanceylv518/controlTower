- 根因：Element Plus 默认顶部 15vh 与自定义最大高度 88vh 合计超过视口；原操作栏仍在滚动区域中。接口错误后空组合区域仍保留高度，区块间距进一步增加内容高度。
- 修改：弹窗顶部留白改为 4vh，高度最多 92dvh；编辑内容单独滚动，操作栏作为不收缩的相邻区域。区域间距从 24–28px 压缩到 14–16px，组合卡片、渠道信息和预览内边距同步收紧。接口错误提示保留，隐藏错误后的空白组合列表。
- 环境限制：远程 Server 尚无组合库接口，界面修正不解决后端版本差异，仍需单独升级。浏览器工具此前不可用，本次未完成真实页面视觉回归；未部署或打包。
- 补修验证：最终压缩间距版本的 pnpm typecheck、pnpm build 均通过，保留既有大包提示；git diff --check 通过。
