# 验收记录：使用日志加渠道 ID 筛选与列（2026-08-19）

范围：c86a4a2（纯前端一笔）。验收环境：Linux,dashboard 包测试、vue-tsc、desktop build 绿。

## 结论：通过,零缺陷

- 前端：渠道 ID 筛选框（非负安全整数校验,非法输入不下发参数）+列表"渠道 ID"列+展开详情行+重置清空;
- **server 端三端点核实全支持**：Logs/LogStat/LogCount 均解析 channel_id（`AND channel_id=?`,非法 400）——列表/统计/精确总数三者口径一致,不存在"列表过滤了总数没过滤"的分叉（验收中曾因取样窗口截断误判 LogCount 缺口,复核为三处齐全,server 侧支持系选路阶段既有,本笔纯接线）;
- 筛选栏网格从 5 列扩 6 列适配。

选路记档沿用：channel 维度在既有选路优先级表内,列表查询走 idx_created_at_id 时序回表滤,渠道过滤大区间可能偏慢——属既有选路设计已知取舍,EXPLAIN 观察项。
