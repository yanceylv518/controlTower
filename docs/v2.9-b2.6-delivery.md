# v2.9-B2.6 delivery note

Automatic dispatch now uses the attributed channel error rate:
`max(total errors - user-side errors, 0) / requests`.

The default user-side status list is `400,413,422`. Total error reporting and
customer/user alerting remain unchanged. Channel alerting and dispatch demotion
exclude only errors that match the configured list. Unknown statuses remain
channel-side.

Production should calibrate `CT_USER_ERROR_CODES` against actual gateway error
semantics before broad rollout. `403` intentionally remains channel-side by
default because it can represent an invalid or expired upstream credential.
