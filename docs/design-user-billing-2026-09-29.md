## 页面建议（待确认）

### 临时账单（新增需求）

用户补充需要临时生成短时间账单，时间范围最好精确到分钟。建议日/月账单为主视图，另设“生成临时账单”入口，不要求先生成完整日账单。

- 选择用户、起止日期时间（精确到分钟，北京时间）以及源库/归档库；支持跨小时和跨日。分钟粒度仅针对筛选输入，明细保留原始时间精度。
- 建议区间采用开始包含、结束不包含，例如10:15至10:45为[10:15:00,10:45:00)，界面明确“截至10:45，不含该时刻”，相邻时间段不重复计数。
- 支持今天截至最近完整分钟的时间范围，不能套用日账单“最多至昨天”的限制；禁止未来或空/逆序区间。创建时固定截止边界，执行中不随时间扩大范围。
- 读取对应来源的请求明细，不按整日汇总比例估算分钟费用。源库任务不依赖完整日账单或归档进度；归档需所选时间段已采集，未确认完整时只能生成明确标识的临时结果，不能承诺最终完整。
- 页面和下载包含区间汇总、按模型统计、按令牌统计、全部区间请求明细及空输出统计。空输出默认包含，仍按原始金额计入；下载文件名与内容均标完整起止日期时间和时区。
- 独立记录为临时区间账单，不能写入日/月完成状态或再次累加到日/月金额；允许与日/月及其他临时区间重叠。明确用途为阶段对账，不能把重叠临时结果重复当成新增应收。
- 相同用户、来源、精确起止时间和规则的重复点击复用在途/已有结果；重生成用显式修订。查重不能只保留日期而丢失分钟边界。
- 保存生成时间、来源、读取截止和完整性证据；临近当前时间的迟到日志可能导致后续差异，显示“临时，截至本次读取”，重新生成产生新版本，不静默改旧文件。
- 待确认：是否需要常用快捷范围（近15分钟、近30分钟、近1小时），以及最长临时区间。以上默认值为建议，不视为已确认实现。

选择用户后切换“日账单 / 月账单”。日账单支持选择日期、查看每日列表；月账单按月份展示汇总和每日统计。生成来源、自动补齐等沿用总方案，本轮不扩展操作细节。

月视图：月累计请求数、用量、金额、空输出请求数及对应金额、数据截止与完整性 → 每日统计 → 按模型/按令牌切换 → 下载月账单。

日视图：当日请求数、用量、金额、空输出请求数及对应金额 → 按模型/按令牌统计 → 空输出请求查看入口 → 下载日账单。

建议空输出摘要显示数量、占比和对应原始扣费金额；这是总数/总金额中的子集，不能重复累加。“空输出”不直接定性为请求失败或扣费错误。具体指标展示仍待用户确认。

## 下载结构

月账单建议一个工作簿三张表：

1. 月统计：用户、账期、请求数、各类用量、费用、空输出统计、覆盖与口径。
2. 每日统计（按模型）：日期 + 模型，分别统计请求数、用量、费用及空输出子集。
3. 每日统计（按令牌）：日期 + 令牌，同样统计请求数、用量、费用及空输出子集。

月账单不默认附带整月逐请求明细；需要请求明细时下载对应日账单。这是对用户本轮所指定月下载范围的落实。

日账单建议包含当日总览、模型统计、令牌统计、逐请求明细；逐请求明细保留空输出标识，文件统计和明细金额一致。

日/月下载默认包含空输出，不新增默认排除策略。是否提供可选排除功能本轮尚未确定；如后续确认需要，应明确标记筛选口径并同步计算所有统计和明细，不能直接覆盖原账单金额。

## 空输出识别与一致性建议

- 建议沿用已知日志语义，以消费记录 type=2 且原始 completion_tokens=0 识别；不能以扣除音频/图像后的“普通输出”为0判断，否则会误标多媒体调用。
- 原始输出字段为NULL或缺失属于未知，不等于0；type5错误单独区分，不混入本轮空输出数量。
- 空输出占比的分母为同用户、同范围纳入统计的消费请求数；分母0显示不适用。
- 模型和令牌维度使用同一批数据、日期及版本，各维度合计分别对齐日/月总计。缺失令牌保留“未记录令牌”分组，不能漏计；同名令牌按ID区分。
- 下载遵循保存的来源与金额快照；默认包含空输出后，页面总金额和下载总金额必须一致。空输出金额是原费用子集，不再额外加减。
- 历史账单若生成时已排除空输出，不能仅改下载开关伪造完整账单；应展示旧口径，必要时显式重新生成。
