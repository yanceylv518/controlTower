# 日账单模型行展开状态与一键操作

用户反馈日期行收起后马上自动展开，并要求一键展开/收起。

原因：工作台每 5 秒刷新并替换表格数据；Element Plus 的 `default-expand-all` 在树数据更新时重新应用，覆盖手动收起状态。

修复只修改 `BillingWorkspaceView.vue`：改为受控 `expand-row-keys`，记录单行选择；增加“全部展开”“全部收起”。初次进入仍默认展开。一键收起后，新刷出的日期也保持收起；手动展开某行不会影响其他行。相同上下文切换日/月页签保留选择，切换实例、账单类型、用户或月份重置。无模型子行时隐藏两个按钮，全部处于目标状态时禁用对应按钮。

验证：

- 实际 Vue + 隔离模拟 API 脚本先复现旧版本首次轮询后可见模型行从 1 变回 3 的问题。
- 修复后单行收起跨两轮真实 5 秒刷新和日/月页签切换保持；手动展开后刷新保持。一键收起后下一轮加入新日期仍全部收起，一键展开后所有日期展开，后续刷新/删除日期保持正确。
- 原有模型详情预选、整日详情重置、合计不重复、旧接口无子行及 390px 页面宽度验证通过，无页面异常与写接口请求。
