## 本次功能

- 常态探针独立并发、首次错峰；默认每10秒发起、30秒未返回计慢，错误后连续加速确认；慢/错各自累计且互不清零，健康成功清零，默认两慢或三错触发熔断。
- 故障锁阻止普通调权及旧排队操作误升权，恢复必须完整执行命令轮次。普通性能权重向下取整可到0，继续探测，探针完整耗时系数参与普通升降权，性能0不借用故障恢复。
- 按站点配置探针间隔、超时、阈值、评估/证据、容量、写入重试、恢复与保留期；配置入口为「调权中心 → 规则设置 → 运行规则 → 探针与恢复」。
- 新增渠道生命线，展示成功率、耗时、慢请求、错误、漏测、逐条探针及CT调权/禁用/恢复等操作；新增日志默认保留7天，可设置1～365天。
- 调权列表默认「已激活」，包含已启用及CT确认自动关闭，保留全部和其他状态筛选。
- 用户折扣补录解除当前NewAPI折扣依赖，结束时间留空可长期有效，修复切用户/站点时的异步旧结果污染；折扣与有效期拆列。
- 补录用户支持全部/有补录/无补录和模型/记录摘要，筛选覆盖完整用户目录及分页。
- 上游账单生成进度及详情刷新保留真实上游名称，兼容归档及历史任务。旧账单不会因发布自动重算。
