# 系统状态页重整

用户要求三实例同屏、去掉网络接收/发送，随后明确移除容器并重新设计。本次在同一会话的 RuntimeView 修改上继续；主工作区既有账单、归档及其他混合改动保留。

## 最终页面

- 宽屏三张实例卡片并排，1280px 以下两列、900px 以下单列；全站既有 1100px 桌面最小宽度不在本次修改范围。
- 每卡集中实例名称/ID、Agent 在线状态、采样时间、CPU/内存/磁盘/近一分钟负载。负载可聚焦/悬浮查看解释。
- 三种百分比指标使用一张 0–100% 资源趋势图，保留全局 1h/6h/24h 范围与自动刷新。
- 健康摘要区分正常、异常、过期和未上报。两分钟过期阈值沿用系统采样阈值；详细检查保留时间，不把旧的成功结果直接显示为当前正常。
- Agent 积压、上报延迟、心跳及健康目标/HTTP/延迟/错误原因放入运行详情，历史与原始采样继续按需展开；原始采样增加负载列，表格高度有界。
- 从启用实例列表建立卡片，无指标的实例仍显示 Agent/健康状态，资源未知用 —，不填零。
- 移除容器 UI 及该页面的 docker-statuses 请求；移除网络收发指标/曲线/采样列。未改变 Agent 采集、Server API 或数据库。
