# 新版账单简明模型单价（2026-09-30）

## 用户要求与实现

只显示单价，不增加旧账单的复杂计价规则。同一模型同一日有多个价格时去重、按数值升序并列，例如「输入 2 / 3；输出 8；缓存读取 0.2」。列头标注账单币种/百万 Token，按次价格单独标注 /次。单价位于用量和原价金额之间。

- 新增 billing.UnitPrices：保存请求发生时的单价集合；采用历史倍率和分组倍率得到结算折扣前有效单价，动态表达式仅在已有拆分逻辑可明确识别时提供数值。只追加展示元数据，不覆盖 Charge.Total、Settlement、配额或折扣。
- 缺失证据显示「未记录」，历史缺失与已知值混合时保留缺失标记；明确零单价保留 0。不能还原的已用音频/图像项目标为未记录。无当前价回填，无金额除 Token 推断价格。
- migration 115 为 billing_compact_daily_totals 增加 nullable JSON unit_prices；页内/跨页合并集合，月账单复制日快照。模型/令牌查询读取集合，在显示时沿账单币种快照换算一次。
- 新版日汇总文件、日明细归档、日明细导出、月统计/每日模型/令牌统计和月页面预览增加简明单价。用户日明细页面新增同列。Excel 单价列自动增加行高、不参与合计，明细导出缓存升为 export-unit-prices-v6。
- 旧明细没有保存价格时显示未记录；已存日 XLSX 保留原数据，不自动生成价格或覆盖。旧版计价规则导出流程不改。
