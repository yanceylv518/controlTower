# 月账单显示实际覆盖日期

用户要求：不足完整月时不能直接显示整月，除非缺失日期已确认无数据。

## 实现

- 月账单的 `range_from/range_to` 保留自然月归属及去重身份，新增 `job.monthly_coverage` 独立表达实际覆盖的连续日期段、缺失日期段、已覆盖/无消费/总天数。区间使用上海业务日期，首尾日期均包含。
- 117 迁移新增 CT `billing_month_coverage`，新月账单在复制日账单的同一事务保存覆盖快照。证据为完整且已结束的日账单、no_data 日任务、CT 已确认无消费的整日检查；不依据金额为零或不存在 compact 行推断无消费。
- 无消费检查须在该日结束后、月账单创建前完成；重新生成范围开始前的旧检查不再有效。未核实日期、当日/未来日期、明确有消费却未出账的日期均不能补齐月份。
- 快照不依赖原日账单保留期限，后续删除日账单/检查或补齐别的日期不会改写该月账单。旧月账单无快照时，仅从本月自身 compact 数据证明覆盖日期，不使用后来生成的日账单/检查补写历史事实；缺失日期继续显示未覆盖。
- 列表显示真实日期段及“部分月账单 · 已覆盖 X/Y 天”，悬停展示缺口；完整月显示完整日期范围，并注明已确认无消费的天数。旧 API 未返回覆盖信息时显示未确认，不回退整月。
- 月预览及用户/上游月汇总 Excel 使用同一覆盖信息。用户 Excel 的较长账期改用整行换行，避免原 A4:B4 窄单元格截断说明。
- 不修改计价、金额、折扣分组、月份去重及自动补齐范围；不增加源库查询。新版读取增加一次 CT 快照主键查询，旧月份回退读取其自身按 job_id 索引的日期。
