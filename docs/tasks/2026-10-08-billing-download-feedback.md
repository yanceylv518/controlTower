# 账单下载状态反馈

## 范围与行为

用户反馈日账单下载准备期间无反馈，并要求检查每个下载入口。覆盖新版用户/上游日月临时账单、账单目录、月预览、日明细全部/筛选导出及重复下载、旧版主账单/完整ZIP/日明细、异常CSV、差异CSV、核对页CSV、旧渠道账单异常导出。当前报表中心页面没有独立下载入口，本次未新增。

统一立即显示准备下载，同一标识跨组件防重复；服务端开始响应时，通过一次性随机token的短期同源Cookie通知前端，成功提示“已开始下载，请查看浏览器下载列表”，失败显示错误，状态释放后可重试。隐藏iframe承接附件/错误响应，避免错误JSON替换当前页面。大文件仍由浏览器流式下载，不加载为整份Blob。不声称文件已经保存到磁盘。未收到通知10分钟后提示先检查浏览器下载列表，避免重复；通知不表示完整文件传输成功。

响应通知已接入账单结果、明细下载、异常和核对接口，无新增迁移/Agent修改，需要Server/Web配套。此前上游渠道拆分改动仍保留，其他会话未提交工作保持。

## 验证

下载通知成功/失败/超时、未提前提示、跨组件重复抑制与状态释放回归通过；账单前端38项回归、类型检查、生产构建通过（既有chunk提示）。后端HTTP回执与上游/用户下载专项、dashboard全包go test/vet通过；保留CSV流式Flush。
