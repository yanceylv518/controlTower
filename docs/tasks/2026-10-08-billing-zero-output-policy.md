# 账单排除零输出请求（2026-10-08）

## 实现范围

- 用户账单默认包含输出为 0 的请求，上游账单默认排除；批量生成、临时账单允许手动调整。自动日账单按相同默认值执行。
- 排除条件为请求 completion_tokens 明确等于 0；缺失值沿用既有异常校验，不擅自视为零。
- 过滤发生在逐请求计费与汇总前，排除行不进入请求数、Token、金额及保存的下载明细。全部被排除时标记无数据，不发布空账单。
- 月账单沿用已保存日账单汇总，不再次查询源库。已有账单直接复用；用户选择覆盖后才重新生成，取消和失败的既有保护保持。
- 生成范围与任务历史保存所选规则，调度重载/与自动目标重叠时读取对应范围的规则；历史记录展示包含或排除空输出。
- 迁移 122 为范围和任务新增 exclude_zero_output，默认 false 保留旧任务选择。新上游自动目标使用 true。
