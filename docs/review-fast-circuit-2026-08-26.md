# 验收记录：批次快速熔断（2026-08-26）

范围：d596f3a（codex 交付,330 行）。验收环境：Linux,vet+全量三树测试、typecheck+build 全绿。

## 结论：通过,零缺陷;两条行为记录

## 机制

Agent 每次上报的渠道增量指标（instance_channel 维度聚合行按渠道汇总）直送引擎快路径——单次上报内 非用户错误率≥阈值(默认 50%)且请求数≥门槛(默认 50) 即刻熔断,不等分钟桶沉降与 EWMA。参数三个进策略(开关默认开/门槛/阈值,校验齐,设置页高级区+说明)。

## 关键核验（既有不变量全守住）

- **并发安全设计正确**：快路径 batch 与引擎 tick 在**同一 select 循环单协程串行**——无状态竞态;ingest 端非阻塞投递（256 缓冲,满则丢快路径退化回常规 EWMA 熔断,带日志）,agent 上报永不被拖慢;
- **auto=已执行态不变量**：写成功才提交 circuit,写失败回滚 normal+计入 write_failed 记账（沿用暂停/退避语义,writeAttemptAllowed 前置检查）;LastWrittenWeight=0 落库,tick 去重不会重发;
- 防护面完整：报告新鲜度≤2min、仅 auto 模型、零权重/多模型渠道跳过、仅 normal 相位（circuit/probing/soft_start 不重复触发）;恢复走既有静默期+探针机制;
- 证据完整（trigger=agent_report_batch/agent/batch id/实测错误率/阈值）;两测试覆盖阈值触发与七类守卫;
- 批次解析：dimension_key 按 ":channel:" 尾段取渠道号,聚合同渠道多行。
