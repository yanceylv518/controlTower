# 账号管理与管理员权限

“访问账号”更名为“账号管理”，保留 `/access-users` 地址。管理员与查看账号分为两个页签。viewer 的页面范围、站点和客户范围规则不变，不支持将 viewer 转为管理员。

管理员可配置姓名、初始密码和功能权限，并支持权限修改、启停及密码重置。权限目录由后端返回，按现有模块授权；其中监控查看、数据查询、操作审计为只读，其余标为管理的权限包含对应模块的写操作。服务器日志任务与 Agent 轮询不在本次实现范围。

## 存储与兼容

迁移 `066_admin_permissions.sql` 为 users 增加 `display_name` 与 `permissions`。权限以 JSON 数组存储：原管理员的 NULL 保留全部权限，新建管理员始终写入显式数组，空数组不授予功能访问权限。`["*"]` 表示全部权限并包含后续新增功能。升级时应将迁移与服务端、前端一同发布，沿用现有迁移流程。

## 权限边界

- 每次服务端请求读取账号最新权限；页面导航重新加载登录信息。权限撤销不依赖用户重新登录。
- 管理员管理接口要求 `accounts.manage`，只能授予自身已有权限，也不能修改或重置权限超出自身范围的管理员。
- 禁止修改自身权限和状态；存储事务锁定管理员记录，避免并发操作停用或降权最后一个有效的全权限管理员。
- 停用、修改本人密码及管理员密码重置均清除目标账号的所有已有会话；其他已登录页面在下一次请求时返回登录页。重置密码也清除该账号在当前进程中的登录失败锁定。
- 现有系统 Bearer Token 保留原服务集成权限，不向新建管理员提供。
- 实例列表是站点选择器的共享依赖；受限账号的返回值按权限隐藏控制配置和 Agent 运行信息。账号管理包含选择 viewer 客户所需的用户查询能力。
- 未映射的 API 默认拒绝受限管理员；新增模块须同步维护服务端权限映射与前端页面映射。

## 审计

操作审计默认向全权限管理员开放，受限管理员需要 `audits.read`；只有具备账号管理及相应可授予权限的管理员可以分配。查看账号不能被授予该权限，后端会拒绝授权，历史残留权限也不生效。

管理员与查看账号的登录、退出、修改本人密码分别记录为 `auth.login`、`auth.logout`、`auth.password_change`，保留结果、身份角色、请求 ID、来源 IP 与认证方式。登录失败记录尝试的账号作为目标，操作者为未验证身份，不将尝试登录者认定为账号本人；密码、密码哈希和会话令牌不会保存。自动调权在写入层排除，历史自动记录也不出现在审计查询中。

审计页面提供时间、目标 ID／请求 ID／错误信息、操作人、固定操作类型及成功／失败筛选。操作人下拉按真实审计操作者模糊检索、去重，最多返回 100 项，包含已删除账号的历史记录。展开区仅显示变化字段，超过 8 行时内容区域内部滚动，最大高度 280px。

操作人下拉选中后精确筛选对应账号，关键词中的 `%`、`_` 按普通字符匹配。目标优先显示快照中的名称并保留 ID；账号变更会先对齐快照层级再比较。登录、退出等单侧记录以两列内容展示，角色和常见状态显示中文。请求 ID 可点击复制；展开详情或阅读后续页时暂停自动刷新，查询失败仍保留筛选区与重试入口。已验证的网页登录身份不会仅因账号名称类似系统账号而被排除。

账号创建、权限/状态修改、密码重置记录为 `auth.account_create`、`auth.account_update`、`auth.password_reset`。操作人来自登录会话，保存用户 ID、账号名、姓名及账号变更快照，不记录密码或密码哈希。全局账号记录在操作审计页中显示，不受站点筛选排除。

## 验证

后端覆盖权限接口矩阵、禁止提权、viewer 保持原角色、实时撤权、密码重置与停用的会话失效、最后一个全权限管理员保护、审计实际入库过滤和权限字段兼容解析。前端运行类型检查与生产构建，并通过临时内存服务检查账号管理页面。真实 MySQL 集成测试需要 `CT_MYSQL_TEST_DSN`。

## 按二级菜单授权

权限选择器与菜单对应：监控分析拆为客户监控、渠道监控、模型监控、系统状态；数据查询拆为用量统计、用户管理、使用日志；账单管理拆为用户账单、上游账单、账单任务、渠道折扣。运行总览、样本分析和延时分诊单独授权。一级分组只是批量选择入口，不作为权限值保存。

旧 `monitor.read`、`data.read`、`billing.manage` 在服务端兼容展开，返回账号信息与编辑保存时使用二级权限，因此取消一个子项不会影响其他子项。无需新增数据库迁移。

共享指标接口必须携带获授权的维度，遗漏或更换到其他维度会返回 403。共享账单任务列表按实际任务类型过滤；账单读取和删除按数据库中保存的类型鉴权，不能通过伪造请求参数切换权限。账单任务权限本身覆盖用户与上游任务管理。

## 个人密码

右上角账号菜单提供修改本人密码和退出登录，所有登录账号均可使用，不依赖系统设置权限。修改密码需校验当前密码、新密码至少 8 位及确认输入；保存成功后重新登录。密码更新与清除会话在同一事务中完成。
