# 调权渠道分组与命名组合

2026-09-18，依据用户确认的交互稿实施。目标分组从站点 NewAPI 的完整分组列表中选择，不在 NewAPI 中的名称不会提交。

## 使用流程

- 调权中心工具栏“分组组合”可提前维护模板，无需选中渠道。
- 点击渠道分组进入“调整渠道分组”，支持多选命名组合，将成员合并去重后替换目标分组；目标分组可从完整分组列表多选或删除。
- 改变所选模板集合会重新生成目标分组；手动调整不改写模板。目标分组可另存为新组合。
- 编辑器完整显示所选分组，预览新增、移除及保存后结果。修改目标后清除此前确认，确认后才允许保存到渠道。
- 组合管理支持新建、改名、成员修改、删除。模板调整不会自动修改已应用的渠道；应用的是当次复制的成员快照。
- 弹窗及控件使用主界面 Element Plus 样式，布局和色彩使用 `--ct-*` 主题变量，移动端组合卡片单列展示。

## 存储与接口

082 迁移新增 Control Tower 自有表 `channel_group_presets`，不修改 NewAPI 数据库结构。每站点保存组合集合、revision、更新人及更新时间。模板共享给该站点有调权管理权限的操作人，不使用浏览器本地存储。

`GET/PUT /api/dashboard/tuning/group-presets?site_id=...` 复用 `tuning.manage` 权限及现有认证/CSRF 保护。PUT 携带 `{items, revision}`，每次原子保存递增版本，过期版本返回 409 `presets_changed`；前端重载最新集合，保留当前编辑草稿供核对。

组合字段为 `id`、`name`、`groups[]`。每站点最多 100 个组合，名称 1–64 字符、不区分大小写查重；ID 唯一。成员去重，规范化后总长最多 128 字符，拒绝空成员和控制字符。空集合可用于删除全部模板，单个模板不可无成员。

## 渠道应用边界

直连站点通过 NewAPI 的 `/api/group/` 读取完整分组列表，Agent 站点从全渠道快照汇总候选；服务端会再次校验每个目标名称，未知分组返回 `400 group_not_found`，不会创建 NewAPI 分组。名称格式、总长度、目标渠道站点归属、显式确认仍保留。现有直连或 Agent 队列、执行结果与审计流程沿用。组合管理本身不会调用 NewAPI 渠道写入接口。

前端要求目标非空且有变化；原有底层接口的显式清空语义保留。选择已有分组不会同步修改用户分组或配置分组倍率，这里只调整渠道的分组匹配字段。
