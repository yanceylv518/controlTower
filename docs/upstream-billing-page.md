# 上游账单页面

2026-09-18 页面整理，入口 `/billing/channels`，实际复用 `BillingRecordsView` 的 upstream 模式。

## 列表

上游作为第一层，账期账单作为第二层。分组键包含站点与上游 ID，不以名称合并；组内按账期倒序，同账期按生成时间倒序，重生成版本全部保留。组头展示名称、ID、站点、份数、待复核数和最近生成时间；点击展开账单，每页最多 20 组。

筛选支持上游名称、ID 或账单编号，账期采用重叠判断且包含选择的结束日期，复核状态沿用 mismatch_rows。统计只计算匹配的已加载账单。接口仍只加载最近 200 条已完成任务，达到上限时显示历史可能不全的提示，不将当前页数量表述为全历史总数。

展开后列为账单编号/计费来源、账期/生成时间、订单与核对、状态、操作；站点和上游不逐行重复。内部任务 ID 在详情及编号悬停可查。账单金额不跨版本重复汇总。

## 详情与窄窗口

详情使用主界面主题、紧凑指标和可折叠计费说明，待复核警告持续显示。弹窗约束在视口内，正文滚动而底部下载栏固定。宽表横向滚动条常显；列表实际容器不足 900px 时操作列不固定，避免遮挡左侧内容。保留原账单主文件、完整 ZIP、每日明细及核对文件的入口和数据范围。
